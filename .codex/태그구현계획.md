# Tag 기능 구현 계획 (TDD)

## 요구사항 요약
1. **생성**: 노트에 태그 지정, 사용자간 태그 비공유, 태그 재사용 가능, 태그명 중복 불가
2. **정규화**: 공백 불허, 대소문자 구분 없음(소문자 저장), 특수문자 불허 (영문/숫자/한글만)
3. **검색**: 태그 기반 노트 검색
4. **삭제**: 태그 삭제 시 전체 노트에서 제거, hard delete
5. **조회**: 노트 조회 시 태그 정보 포함

---

## 구현 순서 (TDD: Repository → Service → Controller)

### Phase 1: TagNameNormalizer (유틸리티)

**테스트 파일**: `src/test/java/prac/demonote/domain/tags/util/TagNameNormalizerTest.java`
**구현 파일**: `src/main/java/prac/demonote/domain/tags/util/TagNameNormalizer.java`

테스트 케이스:
- 소문자 변환 ("HELLO" → "hello")
- 공백 제거 ("hello world" → "helloworld")
- 특수문자 제거 ("hello@#$" → "hello")
- 한글 정규화 ("프로그래밍 공부" → "프로그래밍공부")
- 빈 문자열/정규화 후 빈 문자열 예외
- 50자 초과 예외

```java
// 응답
record TagResponse(UUID id, String name, LocalDateTime createdAt) {}

record NoteTagsResponse(UUID noteId, List<TagResponse> tags) {}
```
